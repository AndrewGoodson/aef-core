# Website drill-down review — 2026-09-12

## Objective and scope

Exercise every public website link and control through browser actions, save a
repeatable action/expected-result ledger, reproduce defects before fixing them,
and repeat the checks after deployment. Scope is the static website; no target
repository integration, model call, or runtime behavior is exercised.

The saved runner is [`site/tests/drilldowns.mjs`](../../site/tests/drilldowns.mjs).
[Setup and replay instructions](../../site/README.md#saved-click-by-click-browser-tests)
include a pinned test-only Playwright installation. Runs use headed Chromium
at 1440, 768, 390 and 320 CSS pixels. The canvas probe reads rendered label
coordinates; sphere selection uses actual pointer clicks. Keyboard and native
selector paths are checked separately.

## Reproduced defects

Baseline source: `7684b4c` with the new test runner, before the product fixes.
The corrected baseline suite produced **216 passes and 9 failures**:

1. Paths `//` and `///` enabled Copy even though they identify the filesystem
   root. This failed twice at each of four widths. Validation now rejects every
   path consisting entirely of slashes.
2. A pending clipboard write could fail after the user entered an invalid path,
   replacing the current validation feedback with a stale clipboard message.
   Failure feedback now uses the same current-command guard as success feedback.

An earlier test-authoring run included incorrect selector and keyboard/reset
assumptions. Those were corrected before the baseline above; they are not
reported as product defects.

The fixed local run produced **225 passes and 0 failures**, with no uncaught
JavaScript exceptions. Its recorded source HEAD remains `7684b4c`; the two-line
product patch was present in the working tree during this run.

## Coverage and retained evidence

The suite covers all six graph spheres and selector details, all four workflow
panels, exclusive selection state, drag/reset, four arrow keys and Home, a full
rotation, pause/resume, reduced motion, offscreen suspension, all three harness
commands, invalid-path recovery, real clipboard copying and simulated permission
failures, disclosure open/close, downloaded instruction bytes, anchor navigation,
outbound navigation, and all seven deployed asset hashes. An inventory assertion
accounts for 18 links, seven buttons, two selectors, one input, one disclosure,
and one canvas. Exact detail text is asserted, not merely visibility.

Local artifacts are intentionally ignored by Git and retained under:

- `output/playwright/drilldown-baseline/`: reproduced failure ledger,
  screenshots, downloads and traces.
- `output/playwright/drilldown-local/`: passing local ledger, screenshots,
  downloads and traces.
- `output/playwright/drilldown-live/`: deployed-site verification.

Each run saves `results.json`, `results.md`, viewport graph/detail/full-page
screenshots, downloaded instructions, four viewport trace ZIPs and a behavior
trace ZIP. Failed steps also save screenshots. The complete final action ledger
is preserved below so results remain reviewable in Git after local traces expire.

## Limits

Responsive widths are Chromium simulations, not physical-device, Safari or
Firefox verification. Clipboard rejection is deliberately injected to exercise
the failure path; successful copying uses the real browser clipboard. Graph
motion remains illustrative, not evidence of learning or runtime execution.

External HTTP availability is recorded separately from correct click navigation.
The private AEF source link requires repository access and returns 404 to the
unauthenticated test browser. Public external destinations are checked for
availability at run time; their future availability is outside this site's
control. No command generated by the page is executed.
