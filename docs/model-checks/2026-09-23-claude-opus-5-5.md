## Deliberately left

- **No default effort.** The guide's claim that `medium` on 5.5 beats `high`
  on Opus 5 is Anthropic's measurement, not this repo's; picking a value
  without measuring it on this corpus is ADR 0193's warning.
- **`docs/research/*.yaml` and cassettes** keep `claude-opus-5`: they record
  what was run, and changing them breaks replay evidence.
- **Preserved thinking, progress-update blocks, computer toolset:** not
  reachable. Both adapters are single-turn with no tools and no replayed
  thinking blocks; the anthropic adapter already reads blocks by `type`.
- **Refusal fallbacks:** already raise `ModelProviderError` so
  `FallbackProvider` falls through (2026-09-03 check). The server-side
  `fallbacks` parameter is not added: it is a beta, and the repo's own
  fallback chain covers it.
