F-M6-3 — `aef loop cycle --runs` is a no-op unless `--module` is also given.

`cmd_cycle` (aef/cli/loop.py):

    graph = load_graph_reference(args.module) if args.module else None

and `harness/loop.py::cycle` runs its harvest leg only

    if runs_dir is not None and corpus_root is not None and graph is not None:

so with `--entrypoint` and no `--module` the flag is accepted, the path is
validated, and nothing happens. Both arms below pass `--no-memory`, so the
cycle stops before proposing and neither costs a live model call. The only
difference between them is `--module`.

The M6 cycle that produced the ledger in 13-ledger.json was arm A's shape, so
its harvest leg never ran. That is not why harvest promoted nothing — §6 of ADR
0163 shows it promotes nothing when it DOES run — but it means the ledger's
cycle is silent about a step it was asked to perform.
