The baseline comes from `_corpus_baseline_manifest`, which reads
`<base ref>:corpus/manifest.json`; the turn's base is the KEPT BRANCH, which
still carries the pre-move manifest. `reconcile` rewrites the manifest ON DISK
from the files on disk — it cannot touch a manifest committed on another ref —
so the command the refusal names is a no-op against the condition the refusal
describes, and it says so ("nothing to reconcile") without contradicting the
refusal. The actual remedy is `git branch -D loop/kept` (or advancing it),
which the message does not mention.

The refusal itself is CORRECT and must stay: a corpus whose splits move
between the base ref and the working tree is exactly the shape ADR 0141 exists
to catch. What is wrong is only the remedy it names.
